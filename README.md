# 第十届曼托杯在线题库

面向手机端的公开在线练习网站，包含 219 道题，支持判断题、单选题、多选题、填空题，以及下皱襞术式和腋窝内窥镜专题筛选。

## 功能

- 按题型、专题和题量自由组合练习
- 每页显示一道题，提交后即时判分并显示正确答案
- 自动统计本次分数
- 在当前浏览器保存每次成绩和逐题答案
- 手机端优先设计，可通过微信二维码进入

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
pnpm install
pnpm run dev
```

生产构建：

```bash
pnpm run build
```
